Publish

  1. Download the file above. Keep the name course-data.json exactly as-is.
  2. Open the ZMI and go to the folder holding index.html.
  3. Rename the existing course-data.json to something like course-data-2026-fall.json. This is your undo — don't skip it.
  4. Upload the new course-data.json into that same folder.
  5. Open the certificate builder and check the footer shows today's date.
